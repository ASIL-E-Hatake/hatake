# hatake（業務定義）for VS Code

hatake の定義を VS Code で**見る**ための拡張機能です。AI が書いた定義を、人が画面のイメージと
「AI と同じ紙」で判断するために作っています（人が YAML を手で書くための道具ではありません）。

**YAML を読まなくても確かめられる**ようにしてあります。左の hatake の欄に定義が業務の言葉で
並び、選ぶとエディタ領域にその画面がタブ付きで開きます。

- **画面**: 動く画面（作り物のデータ・役割を切り替えられる）
- **項目・操作・権限**: 入力欄や列、ボタン、役割ごとの見える・押せるを表で
- **確認**: AI が MCP で見ているのと同じ紙（事実・人が決めること・好み・読み返し）
- **人が決めること**: 全部の定義から集めた問いを、左の欄に画面ごとに

YAML の横で見る道具（プレビュー・問題の一覧・キーの説明・読み返し・スニペット・スキーマの
自動の紐付け）と、版のずれを状態バーで言う仕組みもあります。最初に開くタブは設定
`hatake.view.defaultTab` で変えられます。

0.9.31 は見るだけです（定義は書き換えません）。使い方・注意点・画面の画像は
[VS Code 拡張の手引き](https://github.com/ASIL-E-Hatake/hatake/blob/main/docs/guide/vscode.ja.md)
にあります。

入れ方（Release に貼ってある .vsix を落として）:

```bash
code --install-extension hatake-vscode-<版>.vsix
```

Marketplace には出していません。
